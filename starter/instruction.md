# GitHub Copilot Instructions

## Project Goal
Refactor the legacy Flask Sudoku application into a modern, modular, maintainable web application.

## Coding Standards
- Follow PEP 8 coding conventions.
- Keep functions small and reusable.
- Use descriptive variable and function names.
- Add comments where the logic is complex.
- Avoid duplicate code.
- Separate business logic from Flask routes.
- Handle errors gracefully.
- Write readable and maintainable code.

## Project Structure
- Keep Sudoku logic separate from Flask routes.
- Organize reusable functions into modules.
- Keep HTML, CSS, and JavaScript separate.

## UI Requirements
- Responsive layout.
- Support Light Mode and Dark Mode.
- Alternate colors for 3×3 Sudoku boxes.
- Mobile-friendly.

## Testing
- Use pytest.
- Keep tests independent.
- Test solver, generator, and validation.

## AI Usage
- Explain suggestions before implementing.
- Prefer clean, modern Python code.
- Avoid unnecessary complexity.
